# Dual-monitor PDTester

## Layout

| Display | Role |
|---|---|
| Monitor 1 | Core Jarvis HUD (silent workflow / voice / controls) |
| Monitor 2 | **PDTester** — 6 graphical digests + live stream |

## Digests

VOICE · DESK · BUILD · SYSTEM · HUB · NET — updated live from the activity feed.

## Voice / buttons

- `open pdtester` / `show digests` / **PDTester** button
- `put jarvis on primary` keeps the HUD on monitor 1

## Settings

- `ops_monitor_enabled: true`
- `ops_monitor: secondary`
- `hud_monitor: primary`

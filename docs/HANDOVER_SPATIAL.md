# Spatial gesture workspaces

## Desktop (shipped)

Open the camera, then:

| Gesture | Action |
|---|---|
| Pinch + hold at **right** edge | Throw PDTester → secondary |
| Pinch + hold at **left** edge | Anchor HUD → primary |
| Swipe **right** | PDTester → secondary |
| Swipe **left** | HUD → primary |
| Swipe **up** | Dual layout (HUD primary + digests secondary) |
| Swipe **down** | Stack boards on primary |

Voice: `spatial gestures on` · `spatial off` · `spatial status`

## Deferred

AR glasses / Altium / MetaVerse thin-glass, rotate-to-volume, shard noise scripting.
